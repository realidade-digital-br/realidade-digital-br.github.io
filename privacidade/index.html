Política de Privacidade

← Realidade Digital Br

Vigente desde 11/09/2026.

1. Quem somos e o que este documento cobre

O Realidade Digital Br é um projeto editorial de mídia digital operado pelo seu próprio titular. Esta política descreve o tratamento de dados pelo cliente de API que o projeto usa para enviar vídeos ao seu próprio canal do YouTube.

O cliente de API não é um serviço aberto ao público. Ele é operado exclusivamente pelo titular do projeto, sobre a conta e o canal do próprio projeto. Não existe cadastro, login de terceiros nem área de usuário.

Quanto ao site: ele é composto de páginas estáticas. O projeto não usa cookies, scripts de terceiros nem formulários, e não coleta dados do visitante por meio do site. O provedor de hospedagem pode registrar dados de acesso, como o endereço IP, conforme a política dele.

2. Uso dos YouTube API Services

O cliente de API do Realidade Digital Br usa os YouTube API Services. Ao usá-los, o projeto está sujeito aos Termos de Serviço do YouTube.

O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

3. Qual autorização é pedida

A autorização é concedida pelo titular do projeto por OAuth 2.0, com um único escopo:

  • https://www.googleapis.com/auth/youtube.upload — permite enviar vídeos para o canal autorizado.

Esse escopo não concede leitura de comentários, de inscritos, de histórico de exibição nem de estatísticas de audiência. Nenhum outro escopo é solicitado.

4. O que o sistema NÃO coleta

Sendo específico, porque a ausência importa tanto quanto a presença. O cliente de API não:

  • coleta ou armazena dados de espectadores ou de terceiros;
  • lê comentários, inscritos, histórico de exibição ou analytics;
  • pede, usa ou guarda login e senha de qualquer conta;
  • acessa contas do YouTube que não sejam a do próprio projeto;
  • compartilha dados obtidos das APIs com terceiros;
  • usa dados das APIs para publicidade, criação de perfil ou venda.

5. O que é armazenado, onde e por quanto tempo

Apenas o material de autorização do próprio titular:

  • Identificador e segredo do cliente OAuth e token de atualização — guardados localmente, cifrados pelo mecanismo de proteção de credenciais do sistema operacional, vinculados à conta do titular na máquina. Não são transmitidos a terceiros nem gravados em texto claro.
  • Token de acesso — mantido apenas em memória durante a execução e descartado ao fim; nunca gravado em disco.
  • Registro de publicação — identificador do vídeo, data e resultado do envio, para impedir publicação duplicada. Não contém dado pessoal.

Não há retenção indefinida de dados obtidos pelas APIs, porque nenhum dado de usuário é obtido por elas.

6. Revogação de acesso e exclusão

O titular pode revogar a autorização a qualquer momento em myaccount.google.com/permissions, removendo o acesso do cliente de API. Também é possível revogar pela página de segurança da Conta Google.

Quando o Google indica que a autorização do YouTube não é mais válida, o token de atualização guardado localmente é removido do armazenamento protegido, e uma nova autorização passa a ser necessária. O identificador e o segredo do cliente OAuth — que identificam o aplicativo, e não a autorização — permanecem guardados.

O titular também pode solicitar a remoção dos dados de autorização guardados localmente. Pedidos de exclusão relativos a dados sob controle do projeto são atendidos em até 30 dias.

7. Conteúdo publicado e direitos de terceiros

Os vídeos publicados usam material com direito de reuso verificado e citam a fonte no próprio vídeo e na descrição. Pedidos de correção ou remoção podem ser encaminhados pelos canais oficiais do projeto.

8. Usuários da União Europeia

Quando aplicável, o projeto observa a Política de Consentimento do Usuário da UE do Google.

9. Alterações

Alterações passam a valer na data indicada no topo desta página.
